# Daybook

A monthly money tracker that runs in the browser. Add photos of paystubs, receipts, and statements. Each one files under income, spending, or debt.

Your slips, debts, and photos stay on this device. Nothing in the ledger is uploaded.

## Run it

```bash
npm install
npm run dev
```

Open the page it prints. On a phone, use Share and Add to Home Screen.

Photo sorting needs `XAI_API_KEY` on the server. The rest of the book works without it: you can still type slips by hand.
